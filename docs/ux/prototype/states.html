Policy not enforced (agent bypass / full-access mode)

A session mode, not a status: the agent runs its own tools without asking, so AgentDock’s approval rules have nothing to act on. It is labelled wherever the session is shown, never counted in the inbox badge, and no session ever gets a “protected” badge.

Session header · not enforced
RunningCodexPolicy not enforced

AgentDock policy is not enforced in this session. Codex is running in its own full access mode (reported by the adapter): it runs commands and edits files without asking AgentDock, so approval rules do not apply to what the agent does. AgentDock still asks before the operations it performs itself (push, pull request, merge, worktree removal).

Turning it on through AgentDock · confirmation
Let Codex run without asking AgentDock?

In full access mode the agent runs commands and edits files without sending permission requests. AgentDock’s approval rules will not apply to what the agent does in this session. AgentDock will still ask before it pushes, opens a pull request, merges or removes a worktree.

Cancel is the default button. AgentDock never turns this on by itself.
