# P1-2: Tauri 2 desktop shell, strict CSP, minimal capability and typed IPC

> **繁中摘要**：在 `src-tauri/` 建立 Tauri 2 桌面 host（package `agentdock-desktop`），載入既有的 Vite/React 前端；嚴格 CSP、capability 只給 `core:default` 加自訂 command，不啟用 shell／fs／http 等 plugin。建立第一個 typed command `app_info`、前端 `src/ipc/` 包裝，以及 Rust 與 TS 讀同一份 JSON fixture 的契約測試。另有 smoke 模式（設 `AGENTDOCK_SMOKE_REPORT` 時寫出報告後結束），給 CI 與安裝後測試使用。模型等級：一般模型可，CSP 與 capability 需強模型審查。

Issue: #4 | Gate (#51): G1 (install, start, close, reopen) | Model tier: **standard model** (CSP and capability reviewed once by a strong model)

## 1. Goal and non-goals

Goals:

- Tauri 2 desktop host in `src-tauri/` (package `agentdock-desktop`) loading the existing Vite/React frontend.
- Strict CSP; the capability grants only `core:default` plus permissions for custom commands; **no** shell, fs, http, dialog or other plugins.
- First typed command `app_info`; typed wrappers in `src/ipc/`; a contract test where Rust and TS read the same JSON fixture.
- Smoke mode: with `AGENTDOCK_SMOKE_REPORT=<path>`, after the window is created write a JSON report and exit with code 0 (used by P1-3 CI and the P9-1 installer test).

Non-goals: business commands, database, ACP. No UI redesign; `src/App.tsx` unchanged. No type generator decision (ADR-0003 open question 4; ADR-0004 open question 3).

// src-tauri/src/commands.rs
use serde::Serialize;

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub struct AppInfo {
    pub app_version: String,     // env!("CARGO_PKG_VERSION") of agentdock-desktop
    pub core_version: String,    // agentdock_core::crate_version()
    pub schema_version: u32,     // agentdock_core::SCHEMA_VERSION
    pub platform: String,        // std::env::consts::OS, e.g. "windows"
}

/// Error shape returned by every command (later packets reuse it).
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub struct IpcError {
    pub code: String,    // stable machine code, e.g. "not_found"
    pub message: String, // human text; never contains secrets or env values
}

#[tauri::command]
pub fn app_info() -> AppInfo;

pub fn sample_app_info() -> AppInfo; // fixed values for the fixture test, see §6

## 5. Implementation steps

1. Linux VM: the Tauri system packages from CONVENTIONS §1 must be installed (ask the owner first). Then `npm install @tauri-apps/api@^2.12.5` and `npm install -D @tauri-apps/cli@^2.12.6` (latest on npm 2026-11-22).
2. Create the `src-tauri/` files. `main.rs` starts with `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` and only calls `agentdock_desktop::run()`. `Cargo.toml`: `[lib] name = "agentdock_desktop"`, `crate-type = ["rlib"]` (no mobile).
3. `lib.rs::run()`: `tauri::Builder::default().invoke_handler(tauri::generate_handler![commands::app_info]).setup(|app| { smoke::install(app); Ok(()) }).run(tauri::generate_context!())`. No `unwrap` in `run()`; on failure `eprintln!` the error and `std::process::exit(1)`.
4. Original icon: a simple 1024×1024 geometric PNG made with any drawing tool, then `npx tauri icon <png>` into `src-tauri/icons/`. State in the PR that it is original.
5. Write the §6 tests, then implement.
6. Manual check (owner's Windows machine, or Linux with a desktop session): `npm run tauri dev` shows the window, the existing UI works, the DevTools console has no CSP errors; close and reopen.
7. `npm run tauri build -- --debug --no-bundle` builds `target/debug/agentdock-desktop` (`.exe` on Windows).

`src-tauri/tests/fixtures/ipc/app_info.json` (fixed values, not the current version):

```rust
// src-tauri/tests/ipc_fixtures.rs
use agentdock_desktop::commands::{app_info, sample_app_info};

#[test]
fn app_info_serializes_exactly_like_shared_fixture() {
    let expected: serde_json::Value =
        serde_json::from_str(include_str!("fixtures/ipc/app_info.json")).unwrap();
    let actual = serde_json::to_value(sample_app_info()).unwrap();
    assert_eq!(actual, expected, "Rust AppInfo drifted from the TS contract fixture");
}

#[test]
fn app_info_reports_real_versions() {
    let info = app_info();
    assert_eq!(info.schema_version, 1);
    assert_eq!(info.core_version, agentdock_core::crate_version());
    assert!(!info.platform.is_empty());
}

#[test]
fn capability_file_grants_no_shell_fs_or_http() {
    let text = include_str!("../capabilities/default.json");
    for forbidden in ["shell:", "fs:", "http:", "process:", "dialog:", "opener:"] {
        assert!(!text.contains(forbidden), "capability must not grant {forbidden}");
    }
}

#[test]
fn csp_has_no_remote_sources_or_unsafe_eval() {
    let conf: serde_json::Value = serde_json::from_str(include_str!("../tauri.conf.json")).unwrap();
    let csp = conf["app"]["security"]["csp"].as_str().unwrap();
    assert!(!csp.contains("unsafe-eval"));
    assert!(!csp.contains("http://") || csp.contains("http://ipc.localhost"));
    assert!(!csp.contains("https:"));
    assert!(!csp.contains("*"));
}
```

`sample_app_info()` returns the fixture values.

```ts
// src/ipc/commands.test.ts
import { describe, expect, test } from 'vitest';
import fixture from '../../src-tauri/tests/fixtures/ipc/app_info.json';
import { isAppInfo, isTauri, appInfo } from './commands';

describe('ipc contract', () => {
  test('shared Rust fixture satisfies the TS AppInfo shape', () => {
    expect(isAppInfo(fixture)).toBe(true);
  });
  test('rejects wrong shapes', () => {
    expect(isAppInfo({ ...fixture, schema_version: '1' })).toBe(false);
    expect(isAppInfo(null)).toBe(false);
  });
  test('outside Tauri the wrapper fails explicitly instead of faking data', async () => {
    expect(isTauri()).toBe(false);
    await expect(appInfo()).rejects.toThrow(/not running inside Tauri/);
  });
});
```

## 10. Model tier

Standard model. CSP/capability is a security boundary; a strong model checks in review that nothing extra is granted.

## 11. Common mistakes and pitfalls

- **Forgetting `allow-app-info` in the capability**: the frontend call is rejected (`app_info not allowed`). tauri-build derives permission names from command names; if the name differs, follow the schema generated in `src-tauri/gen/schemas/` and say so in the PR.
- **Committing `src-tauri/gen/`**: build output, excluded by the new `src-tauri/.gitignore` (`/gen/schemas`). The capability `$schema` reference resolves only after the first build on a clean checkout; that is normal.
- `devUrl` with `localhost` while Vite binds `127.0.0.1` (`vite --host 127.0.0.1` in `package.json`) fails to connect; use `127.0.0.1` on both sides.
- Release builds have no console (`windows_subsystem = "windows"`): smoke results must go to a file.
- Whether the Windows CI runner has the WebView2 Runtime is not verified in this repo; if the P1-3 smoke step fails, check that first.
- Do not add `tauri-plugin-shell` / `tauri-plugin-fs` "for convenience"; privileged actions are custom Rust commands (`docs/architecture.md` line 28).
- `app_info` must not return user paths, user names or environment values.
